# Spaceship Titanic — MLOps Pipeline

End-to-end MLOps walkthrough using the [Kaggle Spaceship Titanic](https://www.kaggle.com/competitions/spaceship-titanic) dataset.

---

## Project Structure

```
spaceship-titanic/
├── data/
│   ├── raw/                   # train.csv, test.csv, sample_submission.csv
│   └── processed/             # train_processed.csv (generated by pipeline)
├── src/
│   ├── config.py              # paths, constants, hyperparameters
│   ├── data_loader.py         # load raw CSVs
│   ├── preprocessing.py       # cleaning, imputation, encoding
│   ├── feature_engineering.py # derived features
│   ├── model.py               # GBM training + MLflow logging/registry
│   ├── predict.py             # test-set inference + submission file
│   └── utils.py               # logging / directory helpers
├── outputs/
│   ├── models/best_model.pkl  # serialised trained model
│   ├── figures/               # confusion matrix, feature importance
│   └── submission.csv         # Kaggle submission
├── docker/
│   ├── Dockerfile
│   ├── docker-compose.yml
│   └── .dockerignore
├── app.py                     # FastAPI service (/health, /predict)
├── main.py                    # end-to-end pipeline runner
└── requirements.txt
```

## Phase 1 — Setup

### 1a. Clone the repo

```bash
git clone https://github.com/Ramachandra89/spaceship-titanic.git
cd spaceship-titanic
```

### 1b. Download Kaggle data

```bash
pip install kaggle
# Place your kaggle.json API token in ~/.kaggle/kaggle.json
kaggle competitions download -c spaceship-titanic -p data/raw/
unzip data/raw/spaceship-titanic.zip -d data/raw/
```

---

## Phase 2 — Data Versioning

Raw CSV files are excluded from git (see `.gitignore`).  
For full data versioning add DVC:

```bash
pip install dvc
dvc init
dvc add data/raw/train.csv data/raw/test.csv
git add data/raw/.gitignore data/.dvc
git commit -m "Track raw data with DVC"
```

---

## Phase 3 — Preprocessing & Training

```bash
pip install -r requirements.txt
python main.py
```

The pipeline:
1. Loads `data/raw/train.csv` and `test.csv`
2. Extracts cabin/group features, imputes missing values, one-hot encodes categoricals
3. Engineers `TotalSpend`, `SpendPerAge`, `IsAlone`
4. Trains a `GradientBoostingClassifier`
5. Saves `outputs/models/best_model.pkl` and plots to `outputs/figures/`
6. Writes `outputs/submission.csv`

---

## Phase 4 — MLflow Logging & Registry

Each training run is automatically logged to the local `mlruns/` store.

```bash
# Launch the MLflow UI (SQLite backend)
mlflow ui --backend-store-uri sqlite:///mlflow.db --port 5000
# Open http://localhost:5000
```

To promote a run to the **Production** stage:

1. Open the MLflow UI → Experiments → spaceship-titanic
2. Click the run → register the model
3. In **Models → spaceship-titanic-model** set the desired version to *Production*

## Phase 5 — FastAPI Service

```bash
uvicorn app:app --reload --port 8000
```

### Endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/health` | Liveness check |
| POST | `/predict` | Predict transported status |

#### Example request

```bash
curl -X POST http://localhost:8000/predict \
  -H "Content-Type: application/json" \
  -d '{
    "PassengerId": "0001_01",
    "HomePlanet": "Europa",
    "CryoSleep": false,
    "Cabin": "B/0/P",
    "Destination": "TRAPPIST-1e",
    "Age": 39.0,
    "VIP": false,
    "RoomService": 0.0,
    "FoodCourt": 0.0,
    "ShoppingMall": 0.0,
    "Spa": 0.0,
    "VRDeck": 0.0
  }'
```

#### Example response

```json
{
  "passenger_id": "0001_01",
  "transported": false,
  "probability": 0.12
}
```

Interactive docs available at **http://localhost:8000/docs**


## Phase 7 — AWS EC2 Deployment

```bash
# On your EC2 instance (Amazon Linux 2 / Ubuntu)
sudo yum install -y git docker          # or apt-get for Ubuntu
sudo systemctl start docker
sudo usermod -aG docker ec2-user
# Re-login for group change to take effect

# Install Docker Compose plugin
sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -SL https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 \
  -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose

# Clone / pull the repo
git clone https://github.com/Ramachandra89/spaceship-titanic.git
cd spaceship-titanic

# Copy trained model artefact (scp or S3) to outputs/models/best_model.pkl

docker compose -f docker/docker-compose.yml up --build -d
```

Ensure port **8000** is open in the EC2 Security Group inbound rules.

## Phase 8 — Evidently Drift Report

```bash
pip install evidently
```

```python
import pandas as pd
from evidently.report import Report
from evidently.metric_preset import DataDriftPreset

reference = pd.read_csv("data/processed/train_processed.csv")
current   = pd.read_csv("data/processed/test_processed.csv")

report = Report(metrics=[DataDriftPreset()])
report.run(reference_data=reference, current_data=current)
report.save_html("outputs/drift_report.html")
```

Open `outputs/drift_report.html` in a browser to review feature drift.
